IBSOpenInsurance Upload

IBSOpenInsurance Upload is an internal batch program. It uploads report files (zip) created by the IBSOpenInsurance export job to the Google Drive of the account that authorized it.

It uses only the Google Drive permission drive.file: it can see and change only the files and folders that it created itself. It cannot read any other file in your Google Drive.

It is not a public service and is used only by its owner.
