Privacy Policy - IBSOpenInsurance Upload

Last updated: 20 November 2026

What the app does

IBSOpenInsurance Upload is an internal batch program. It uploads report files (zip) from the computer where it runs to the Google Drive of the account that authorized it.

Google user data

  • The app requests only the Google Drive scope https://www.googleapis.com/auth/drive.file. It can access only the files and folders that it created itself.
  • It reads the email address of the authorized account only to write it in its own local log file.
  • It does not read, collect, sell or share any other Google user data.
  • The login token is stored only on the computer that runs the app and is never sent to anyone else.

Data sharing

No Google user data is shared with third parties.

Removing access

You can remove the app's access at any time at https://myaccount.google.com/permissions.
